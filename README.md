A fast single-pass Markdown parser written from scratch, byte-identical to marked 18.1.3 (default options: GFM on, breaks off) on the practice set. Dependency-free ES module: `parse.js` exports `parse(markdown)`, and `main.ts` drives it over `/input/cases.json` to `/output/html.json`.

## Run it

```sh
node main.ts
```
